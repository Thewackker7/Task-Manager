# Task Manager API

A backend Task Management REST API built using **Python, FastAPI, and PostgreSQL**. This project focuses on developing a scalable backend with clean architecture, database integration, authentication, automated testing, containerization, and CI/CD.

## Tech Stack

- **Language:** Python
- **Backend Framework:** FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Validation:** Pydantic
- **Containerization:** Docker & Docker Compose
- **Testing:** Pytest
- **Code Quality:** Ruff
- **CI/CD:** GitHub Actions

## Project Goals

- Build RESTful APIs for task management.
- Implement user authentication and authorization.
- Design and manage relational databases.
- Follow clean and modular backend architecture.
- Write automated tests.
- Containerize the application using Docker.
- Automate testing and deployment workflows using CI/CD.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/Thewackker7/Expense_tracker.git
cd Expense_tracker
```

Start the application using Docker Compose:

```bash
docker compose up --build
```

Access the API documentation:

```text
http://localhost:8000/docs
```
